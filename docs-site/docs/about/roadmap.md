# Roadmap

Near-term priorities:

- Improve accessibility and camera feedback on the public kiosk.
- Add a hardened HTTPS deployment profile for access from other devices on a
  school network.
- Add complete active-loan and circulation reports.
- Improve copy-label batch printing.
- Add optional class filtering for large borrower lists.
- Expand import validation and downloadable CSV templates.

Longer-term ideas:

- Optional multi-book image recognition with explicit review.
- Pluggable local and remote recognition providers.
- Offline metadata caching.
- Notifications and printable loan receipts.
- Multiple language support.
- Optional student privacy modes for shared kiosks.

**Multi-book recognition must remain an identification aid.** Shelf-School will
continue to require a catalog match and a specific physical copy before a loan
can be confirmed.
